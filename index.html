Before you start

Remote in hand. TV on.

  1. Keep the remote near your iPhone. Gently move it or briefly press an arrow button to keep it awake.
  2. Tap Choose a device. Only select a device you recognize as the remote. If none appears, cancel.
  3. Check the selected name, then tap Try connection. Keep Safari visible for the 10-second check.

Use normal, short button presses. Leave the remote paired to the TV; don’t hold any reset or pairing button combinations.

What this test can tell us

It uses beacio’s standard requestDevice() chooser and gatt.connect(). A remote already connected to the TV may not appear or accept another connection; this test cannot establish the cause of a failure.

No characteristics are read or written, and no pairing reset is requested. The page requests disconnection after 10 seconds, when you stop, or when you leave the page. A short connection may temporarily affect TV control.

The standard GATT connection API has no connected-device RSSI polling method. This page generates no distance or hot/cold readings. Device names can be duplicated or misleading.

API references: beacio documentation and GATT connection API.

Everything runs on this device. No analytics, server uploads, saved device IDs, or saved names. The downloaded report excludes device names and identifiers. Share it only if you choose.
